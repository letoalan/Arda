# TextureFilters.tsx

## Description
Le composant `TextureFilters` injecte un conteneur SVG masqué dans le DOM définissant l'ensemble des filtres SVG réutilisables par le calque de texture de carte (`MapOverlay`).

## Filtres SVG Définis
| Identifiant ID | Style Associé / Époque | Description Technique |
| :--- | :--- | :--- |
| `parchment-rough` | Antiquité | Bruit fractal à 3 octaves, saturation 0.3 |
| `parchemin-gold` | Moyen Âge | Effet doré parchemin médiéval |
| `parchment-fine` | Moyen Âge | Bruit fin léger |
| `engraving-copper` | Moderne | Simulation de gravure sur cuivre |
| `circuit-glow` | Futuriste | Flou néon pour esthétique cyberpunk |
| `parchment-coarse` | Antiquité & Tolkien High/Dark Fantasy | Bruit fort à 4 octaves |
| `paper-heavy` | Renaissance | Texture de papier vélin lourd |
| `paper-smooth` | Époque Moderne & Tolkien Light | Grain épuré pour carte papier lisse |

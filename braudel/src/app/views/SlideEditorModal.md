# SlideEditorModal.tsx — Éditeur de Diapositive 16:9

Ce composant permet la composition interactive d'une diapositive d'appui attachée à une scène de récit ou un waypoint historique.

## Fonctionnalités V1

- **Canevas de référence 16:9** : Garantit un affichage identique entre l'édition et la projection.
- **Ajout d'éléments** : Texte typographié, Image par URL, Formes géométriques (rectangle, cercle).
- **Magnétisme / Grille (Snapping)** : Pas de 10px pour aligner aisément les coordonnées `x, y, w, h`.
- **Inspecteur de propriétés** : Modification du contenu textuel, taille de police, couleurs, et suppression.

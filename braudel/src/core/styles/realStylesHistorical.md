# Documentation du fichier `realStylesHistorical.ts`

## Rôle
Définit les configurations visuelles et cartographiques des styles historiques du monde réel (Antiquité, Moyen-Âge, Renaissance, Époque Moderne, Wargames Guerre Froide, etc.).

## Styles Clés
- **`military_tactical_wargames`** : Thème WarGames NORAD WOPR (1983) rétro-informatique avec effet terminal/moniteur CRT phosphore vert (`#22c55e`), scanlines, grille tactique et différenciation nette terre/mer :
  - **Mer / Océans (`water`)** : Bleu marine radar profond (`#07182c`)
  - **Terres (`landcover`)** : Vert radar sombre (`#0d381e`)
  - **Limites / Côtes (`borderColor`)** : Vert phosphore WOPR (`#22c55e`)

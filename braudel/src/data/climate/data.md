# Documentation — Données Climatiques (`src/data/climate/`)

## Rôle & Responsabilité
Ce dossier regroupe les jeux de données climatiques statiques du Mode Braudel :
- `paleoclimate_history.json` : Série paléoclimatique historique de -3000 à 2026 (optimum holocène, période romaine chaude, anomalie médiévale, petit âge glaciaire, éruptions majeures de 536 et 1815, réchauffement moderne).
- `rcp_scenarios.json` : 4 trajectoires RCP (RCP2.6, RCP4.5, RCP6.0, RCP8.5) du GIEC pour la période 2026-2100.

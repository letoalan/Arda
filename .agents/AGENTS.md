# Project Rules

- **Artifact Synchronization**: After creating or updating the `task.md`, `../prompt/prompts/implementation_plan.md`, or `../prompt/prompts/walkthrough.md` artifacts in the standard `.gemini` brain directory, you must systematically duplicate them into the root directory of this project (`c:\Users\alano\WebstormProjects\braudel\`). Note: for `task.md`, append your execution checklist to the existing project `task.md` rather than overwriting it, as it contains the global project roadmap.
- **Wiki-as-Code & Continuous Documentation**: Any creation of a new source file MUST be accompanied by a corresponding `.md` technical documentation file at the same level. Any addition or modification in an existing source file MUST be documented immediately in its associated `.md` file, as well as in its parent sector/directory `.md` file. The documentation must always reflect code evolution in real time as a fundamental system constraint.
